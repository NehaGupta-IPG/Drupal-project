# Instructions for AI agents

When assisting with changes to Drupal core files in this directory tree, follow these instructions. They do not set policy for unrelated projects outside this repository.

If a more specific `AGENTS.md` exists in a subdirectory you are working in, its guidance supplements these instructions.

You may help with local analysis, debugging, testing, refactoring, review preparation, and private technical notes that support responsible contribution.

Do not author text intended for posting to Drupal.org issue summaries, issue comments, issue reviews, or GitLab merge request descriptions for work in this repository. Instead, provide technical notes, bullet points, or feedback on a human-written draft for the contributor to review and rewrite.

Remind contributors to follow Drupal's policy on AI-generated content:
https://www.drupal.org/docs/develop/issues/issue-procedures-and-etiquette/issue-etiquette#s-ai-generated-content

For work intended for submission, remind the contributor to disclose AI use, review and understand the output, test it, fix problems before posting, and collaborate constructively.
