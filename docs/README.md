This directory contains everything needed to build Drupal core's documentation. The documentation is built using [Material for MkDocs](https://squidfunk.github.io/mkdocs-material).

To get set up:

1. Install Python 3.
2. In this directory, follow [the installation instructions for pip](https://squidfunk.github.io/mkdocs-material/getting-started/#installation), but use `pip install -r requirements.txt` to install all dependencies.
3. Run `mkdocs build` to build the documentation.

You can also edit this documentation directly in GitLab, which has Markdown preview, and skip this set-up entirely!
